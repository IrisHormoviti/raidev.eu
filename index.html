Software I use

Krita
For drawing

I used to use CSP, but after switching to Linux, I had to find something new.

Nowdays I'm pretty comfortable in krita after setting it up the way I like, and it's really good considering it's completely free and open source.

Godot Engine
For game development

It's what I'm using to make Mira's Journal. What can I say? It's what taught me programming in the first place.
It has solid tools tools for both 2D and 3D, UI tools better than most other engines and is free with no fine print.

Aseprite
For pixel art

If you do pixel art and don't use Aseprite, you're doing something wrong.
It's more than worth the small price imo. Just don't make the same mistake as me of buying it on Steam...

Obsidian
For note taking

I mostly use it for Mira's Journal design documents.
It does the job as a markdown editor, I just wish there was a better free way to sync it than Git.

Micro
As text editor

VS Code is owned by Microsoft, Vim is too complicated, Nano is too basic, and I don't even know what Emacs is.

Micro is the only good text editor I've found. It uses standard keybinds (Why is that unusual in CLI editors???) and has enough configuration options to make it comfortable.

Though, sometimes I still result to using VS Code (or Codium), just because it's more convinient for this like webdev or Unity.

Hardware I use

rat-box
Desktop PC
  • Case / Motherboard: ASRock DeskMeet x600
  • CPU: AMD Ryzen 5 9600X
  • GPU: AMD Radeon RX 9060XT
  • RAM: 16GB DDR5
  • Storage: 2TB NVMe SSD
  • OS: Arch Linux

It was really hard to get a good deal on anything in 2026. I really had to pay 200€ for 16GB of ram... But the DeskMeet really helped in this case, since it came with a case, an MB and a PSU in ITX size for a decent price.

I do wish it was a bit quiter, and had more than 16GB of ram, but I can deal with it for now.

Iris-Yoga-7
2-in-1 Laptop
  • Model: Lenovo Yoga 7 14ARP8 (2022)
  • CPU: AMD Ryzen 7 7735U
  • GPU: AMD Radeon 680M [Integrated]
  • RAM: 16GB (2GB reserved for graphics)
  • Storage: 1TB NVMe SSD
  • Display: 14' 1920x1200 (16:10) OLED, HDR
  • OS: Bazzite

I got this laptop when I entered university. I was specifically looking for a 2-in-1 which I could also use as a drawing tablet. And it's a decent laptop. The screen is fantastic, the keyboard is nice, it came with a pen, it's got good IO and servicable preformance.

There's two issues however: Linux compatibility and how fucking hot it gets!

I've always been using Linux on this thing. I started with fedora, at some point I used nixos (it sucked), and now it's on bazzite.

When I first got it, there were issues with the tablet mode where the keyboard wasn't disabling. That's now been fixed in the Kernel.

There is still a really weird issue with the touchpad where it just gets unresponsive at random, and I have to restart the i2c driver. In all these years, I still haven't been able to fix it. It also gets significantly slower after each consecutive time it goes to sleep for whatever reason. Sleep is always an issue with these windows laptops.

It's fine though, it's served me well even with all these quirks.

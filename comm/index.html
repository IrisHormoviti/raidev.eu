Pricing

Price ranges from 15-55€

Base price: 15€ (for a headshot sketch)
+5-15€ for bust to fullbody
+3€ for color
+8€ for shading
+10-20€ for background
Additional characters are also a +8€, with the same rules applying for bust/fullbody.
This applies to smaller scale art with many frames, such as sprite sheets. For static character art, key art and the like, refer to "Illustration".

Sprite design: 10€.
The same character with a diffrent outfit would count as unique design.

16x16: +1€ per frame.
24x24: +2€ per frame.
32x32: +3€ per frame.
48x48: +4€ per frame.
64x64: +5€ per frame.
Higher res or hand-drawn: +8€ per frame.
If not exact, round up. The resolution refers the base character, any extensions (like a sword held forward) won't add to the price. If the sprite is not square, refer to the size of the biggest axis.

Shading: +5€ for each design.

For example, a sheet of 24x24 walk sprites with a 3 frame walk cycle would be 22€. Any single sprite is just 3€.

To order a comission, please contact me preferably on Discord @raidev, or on Bluesky @raidev.eu.
Prices are listed in Euro, you can try converting them to your local currency. Before commissioning, please review the terms below.
